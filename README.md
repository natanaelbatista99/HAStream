# HAStream Python Version

This repository contains the code corresponding to the techniques and experiments proposed in the article. **"Efficient multiple density-based models over large datasets with data stream applications"**, published in Applied Soft Computing 2025, as well as the instructions to reproduce the results reported in the paper.

This implementation utilizes multiple CPU processes to optimize the execution of the multiple hierarchies generated by HASTREAM. This short guide includes the 4 steps needed to reproduce the results reported in the paper: 
1. [Installation](#installation)
2. [Folder Structure](#folder)
3. [Running Experiments](#experiments)
4. [Results](#results)

## <a id="installation"></a> 1. Installation

The first step for installing the project consists of downloading the code from the repository publicly available at Github. Note that if this repository has been already downloaded as ZIP file, the clonning of the Github repository is not necessary. 

```
git clone git@github.com:natanaelbatista99/HAStream.git
```
Next, change to the project folder and create a virtual environment that will contain the packages and dependencies needed to run the HASTREAM project. 

```
python -m venv env
```
Or install the specific version of Python:
```
py -[version] -m venv venv
```

After the virtual environment has been created, it must be activated so the installation of the dependencies is done in the virtual environment.
```
source env/bin/activate
```
or
```
venv/Scripts/activate.ps1
```

Next, run the following command to install the required dependencies listed in the `requirements.txt` file. 
```
pip install -r .\requirements.tx
```

If you don't have the **pip package**, install it:
```
python.exe -m pip install --upgrade pip
```

Install the version of PyTorch that matches the recommended system version:
```
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

At this point, the installation should be ready for use.


## <a id="folder"></a> 2. Folder Structure


```
├── datasets/
├── denstream/
    ├── denstream.py
    ├── experiment_config.py
    ├── main.py
├── hastream/
    ├── hastream.py
    .
    .
├── experiment_config.json
├── main.py
├── requirements.txt
```

The `dataset` folder contains the CSV files corresponding to the synthetic and real data.

The `denstream` folder contains the execution files for the DENSTREAM algorithm.

The `hastream` folder contains all the classes for executing the HASTREAM algorithm.

The `experiment_config.json` file is used to define all parameters of the HASTREAM algorithm. FORMAT:
```
 "dataset_name.csv": { 
     "dataset": "dataset_name_files", 
     "beta": 0.75, 
     "mpts": "[x for x in range(x1, x2, step)]", 
     "min_cluster_size": 10, 
     "decaying_factor": 0.035, 
     "mu": 2, 
     "n_samples_init": number, 
     "epsilon": 0.003, 
     "percent": 0.xx, 
     "method_summarization": "single", 
     "stream_speed": 100, 
     "runtime": true, 
     "plot": true, 
     "save_partitions": true 
 },
```

## <a id="experiments"></a> 3. Running Experiments

To run the algorithm, execute the following command:
```
python3 main.py <name_of_dataset.csv>
```
Remember to put all the dataset parameters in the `experiment_config.json` file before running.

## <a id="results"></a> 4. Results

When HASTREAM is run, a folder called `results` will be generated in the root directory, containing a subdirectory with a folder named `<name_of_dataset>` named after the dataset. This folder will contain the partitions of the multiple hierarchies *mpts*, the result images of the partition in the case of a 2D dataset, and the output logs.
